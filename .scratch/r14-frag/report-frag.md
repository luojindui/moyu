## 三次打开记录

### 打开1（首日首次，新档，moyu≈3）
- 步数：👥 1 下 → 「工位」tab 1 下 = **2 步**到工位；精力 3 下；今日摸鱼卡打断 +2 步（点「今天先不选」）；点买不起的灰按钮 1 下（无任何反馈）。
- 滚动：工位内容 651px / 可视 613px → **溢出 38px，最多 1 次小滚**；首屏 10/11 行完整可见，最后一行「工位猫窝」被切 38px（无滚动条/无渐隐提示）。
- 信息量：11 行 = 3 精力 + 8 家具；非空白 **251 字 / 32 个数字 / 16 个加成词**，一屏内。
- 决策：家具 8 件全灰（当天 0 件买得起，按钮只有裸价格"3000/2.00万…"，没有"还差多少"）；精力 3 条成本是 18px 圆点里的裸数字 40/35/25，**40+35+25=100，正好可以全选，但 UI 没写** → 唯一需要"算一算"的点。
- 打断：开页 ≈12s 时「今日摸鱼卡」整页盖住工位（cards z16 > team z13），点家具按钮的位置被 cards-head 挡住，必须 +2 步才能继续。
- 感受：2 分钟里正经事只有「点 3 下精力」（~10-20s）；8 行灰价格像看菜单，工位在首屏没有任何入口提示（body 内无"工位/精力"字样）。

### 打开2（同日稍后，grant 1e11）
- 步数：2 步到工位；买第 1 件 1 步 → toast「已装修：绿萝」+ 行变绿✓ + 汇总 0/8→1/8；连买 8 件 = **8 步全成功**，余额实时扣，无二次确认。
- 滚动：富态页溢出 5px ≈ 0 滚；全部买完内容缩到 533/533px → **0 滚动，11 行全✓、0 个可点按钮**。
- 反馈：toast 可见（z45 在弹窗之上），但 toast 固定 top:108px **正好盖住 tab 行**（工位 tab 被遮 1.8s，pointer-events:none 不挡点击）；家具按钮 27-30px 高，整行文字区域点不动。
- 场景：关面板后 8 件家具真的画进场景（绿萝/迷你冰箱/鱼缸/猫窝+猫/地毯/台灯肉眼可辨；投影仪光斑、按摩椅与原有窗光/桌影重叠，辨识度一般）。
- 同会话再开：**1 步**直达工位（上次 tab 被记住）。
- 感受：这是整套系统最爽的一刻，「看得见的成长」成立；但只有"有钱的那几次打开"才有这一下。

### 打开3（同日再开 → 模拟次日 → 小屏 375×667）
- 同日再开：工位 11/11 全✓、**0 个可点、精力 0/100** → 打开即"死看板"；HUD 上 👥 有任务红点 1、天赋角标 1，但**没有任何"精力还剩/工位可玩"提示**。
- 模拟次日（存档 energy.date 回拨，先 `__MOYU__.rewindSave(2)` 防 pagehide 覆盖）：精力正确重置 100/100，工位 3 个「使用」可点、8 行家具✓；2 步到工位 + 1 步用精力，真人 ≈10-15s。
- 小屏 375×667：body 461px / 内容 555px → **1 次滑动**；首屏 8/11 行完整，鱼缸/投影仪/工位猫窝在折叠线下。
- 感受：每天只有「第一次打开」有事做；第 2-6 次打开工位是空的，游戏也不提醒 → 碎片党会彻底忘掉这个 tab。

## 结论：不是"每次打开有事做"，也不是"打开就要做功课"
是「**每天第一次打开 10-20 秒有事做，其余打开是空看板，而且完全不提醒**」。两套系统本身很轻（不需读表格/不需比较），但回访钩子不可见 → 对碎片党来说等于没做。

## 问题清单
- **P0：无**（无崩溃/数据错误/卡死；live 与 dev 一致，线上 bundle 含"今日精力/工位猫窝/已装修"）。
- **P1-1 入口不可见，精力无回访提示**：home 无"工位/精力"字样；👥 只有任务红点 + 天赋角标，工位 tab 无 badge；同日再开精力 0/100 无提示，次日 100/100 也无提示。碎片党只会走"点👥领任务"路径。
- **P1-2 "3 选"其实能全选，却在逼玩家算**：40+35+25=100，实测连点 3 次全成功（剩 0/100）；页面只写"每天 100 点…"，成本是裸数字无单位，没有"可全用"文案 → 要么纠结、要么只点第一行（白丢 +28% 挂机 / +80% 巡逻）。
- **P1-3 首日摸鱼卡整页盖住工位（模态叠加）**：开页~12s 弹卡，cardsZ=16>teamZ=13，team 仍开着，买按钮位置命中 cards-head；boss 有 anyModalOpen 延后逻辑，cards 没有。
- **P2-1 按钮/可点区偏小**：工位 tab 54×34、精力「使用」44×30、买家具 27-30px 高；点行内文字（hit=talent-desc）无反应，只有右侧小按钮生效。
- **P2-2 钱不够时 8 行灰价格只显示裸价格**，无"还差 X"/无折叠；390×844 最后一行被切 38px、375×667 有 3 行在折叠线下，无滚动提示。
- **P2-3 反馈 toast 盖住 tab 行**（top:108px，正好压住 工位 tab 1.8s）。
- **P2-4 8/8 买完没有收尾反馈**（无庆祝/无一次性奖励），工位变成 11 行✓的静态页。

## 改法建议（3 条）
1. **给每日精力一个 1 步回访入口**：👥 按钮复用现有 badge 机制加「精力」角标（未用完时显示次数），或打开面板时若有剩余精力默认落工位页/给工位 tab 加小圆点；配一句"今天还能用 3 次精力"。
2. **精力改「一键全用」+ 去掉心算**：标题写"今天 3 项可全用（40+35+25=100）"或加「全部使用」按钮（3 步→1 步），成本圆点改成"40 精力"。
3. **修点不动的摩擦**：买家具/使用按钮整行可点（或高度≥44px）；钱不够时折叠成一行「下一件：绿萝 3000（还差 2997）」；面板已开时延后弹摸鱼卡（复用 boss 的 anyModalOpen 逻辑）。
