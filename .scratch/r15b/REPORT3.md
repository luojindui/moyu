## 复验通过项
- **① 接咖啡能玩**：逐帧下落 65.7%→76%→86.7%（同一颗）；杯口线 88%；接住变绿；漏接变暗且扣分（漏 2 → 496 = 25×10×2 − 4）。
- **② 破纪录仪式**：先读旧值再结算；首局旧 0 有庆祝，旧 9999 时不庆祝（显示"历史最高 9999"）；结算含奖励行/明细/再来一局/返回。
- **③ 持久化**：刷新后最高分 496/6250/1065 保留、0/3 文案保留；同一天 reload 角标（played=1→"2"、aria 正确）正常。
- **④ 限制/奖励/早退**：0/3 →「今天玩完了，明天再来」+按钮「明天再来」disabled+aria「今天已玩完」；<2s Esc 退还次数（played 仍 0、角标回 3）；6.2s Esc 弹确认框、确认后扣 1 次、+3（按已玩比例，未接线的 +254 已修）。
- 线上关于面板：v0.5.0 · 2026-11-27；无 console 异常。

## 判断
- **记录动力（够不够）**：**短线够（6/10）**——仪式感+旧值+明细+再来一局+最高分+角标齐全，三游戏各有技巧空间；**长线不够**——无成就墙/历史榜/累计；3 次共享（每游戏每天至多 1 次）；天花板低且已接近：咖啡上限≈540（已 496）、节奏上限 1180（已 1065），1~2 天打满后只剩 +25/+30 奖励；找老板上限高但 8000 封顶。

## P2（不阻塞）
1. **跨日 boot 角标缺失**：昨天 played=3 → 今天 boot 重置 0/3，但角标 null、aria 默认「摸鱼站小游戏」（实测 state played=0）。同 0/3 reload 时 aria 也未播报「已玩完」。
2. **<2s 退还次数无提示且文案误导**：toast 仍说「得分 0，没拿到奖励」，玩家不知道次数已退还。
3. **关于/更新日志仍无摸鱼站**：线上 updates.json v0.5.0 notes 仍是批 3 内容（发现性；所幸 🎮 角标 3 有引导）。
4. **咖啡宽容窗**：落地变暗后 0.32s 内仍可接住（代码未变，本轮未在线上重测）。
5. **找老板 >8000 上限**：结算分与写档最高分不一致（本轮 6250 未触发，属边缘）。
6. **中途退出无结算页**（只有 toast），与正常结算不一致。

## 结论
**可交付：是**（线上包验证通过，无 P0/P1；P2 建议顺手修 1/2/3）。成就墙非本批门槛。
