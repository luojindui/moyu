# Delta specs: mvp-v1

## Requirement: 点击摸鱼
玩家点击场景中任意位置获得摸鱼值。
#### Scenario: 点击场景加钱
- **WHEN** 玩家点击/触摸游戏场景
- **THEN** 摸鱼值增加当前点击力，场景浮现 "+N" 飘字
#### Scenario: 连续点击
- **WHEN** 玩家 1 秒内点击 5 次
- **THEN** 摸鱼值累计增加 5 × 点击力

## Requirement: 被动收益
不点击时工位自动产出摸鱼值。
#### Scenario: 按时间累加
- **WHEN** 游戏运行且经过 t 秒
- **THEN** 摸鱼值增加 idleRate × t（误差可忽略）

## Requirement: 升级购买
玩家消耗摸鱼值购买升级，提升点击力或被动收益。
#### Scenario: 购买生效与涨价
- **WHEN** 摸鱼值足够时购买某升级
- **THEN** 扣除当前价格，效果即时生效，该升级价格按 1.15 倍上涨
#### Scenario: 余额不足
- **WHEN** 摸鱼值低于价格时尝试购买
- **THEN** 购买被拒绝，摸鱼值与升级状态不变

## Requirement: 本地存档
游戏状态自动持久化并在重开时恢复。
#### Scenario: 恢复
- **WHEN** 页面重新打开且存在有效存档
- **THEN** 摸鱼值、升级状态恢复为存档值
#### Scenario: 损坏兜底
- **WHEN** 存档 JSON 解析失败或字段非法
- **THEN** 忽略存档并以初始状态开始，不抛错

## Requirement: 离线收益
关闭页面期间的被动收益按上限结算。
#### Scenario: 正常离线
- **WHEN** 离线 30 分钟后返回
- **THEN** 结算 idleRate × 1800s 并弹出欢迎回来面板显示数额
#### Scenario: 上限封顶
- **WHEN** 离线 24 小时后返回
- **THEN** 只结算 8 小时对应的收益

## Requirement: 摸鱼值显示格式
大数字用中文单位缩写。
#### Scenario: 万位
- **WHEN** 摸鱼值为 123450
- **THEN** 显示为 "12.35万"

## Requirement: 手机适配
竖屏手机浏览器可正常游玩。
#### Scenario: 视口与触控
- **WHEN** 以 375×667 视口打开
- **THEN** 布局为竖屏三段式（HUD/场景/商店），触摸即点即响应，无横向滚动

## Requirement: 老板巡逻（随机事件，批次2）
游戏中随机出现老板巡逻窗口，玩家需停止点击躲避。
#### Scenario: 巡逻出现与躲避
- **WHEN** 老板巡逻进行中且玩家不点击直至结束
- **THEN** 巡逻结束后获得奖励摸鱼值（与进度正相关）
#### Scenario: 巡逻中手滑被抓
- **WHEN** 巡逻窗口内玩家点击
- **THEN** 摸鱼值按比例损失，且场景显示被逮提示

## Requirement: 同事丢梗（随机事件，批次2）
场景随机出现可点击的奖励目标。
#### Scenario: 点击奖励
- **WHEN** 梗出现在有效期内被点击
- **THEN** 获得一次性奖励摸鱼值
#### Scenario: 错过
- **WHEN** 梗超过有效期未被点击
- **THEN** 无奖励，无惩罚

## Requirement: 可被 agent 试玩
游戏暴露只读调试钩子与离线模拟入口，供无视觉的 agent 玩家测试。
#### Scenario: 调试钩子
- **WHEN** 页面加载完成
- **THEN** window.__MOYU__ 提供 state 快照、fps、资源加载状态、存档时间戳与 reset，且引擎级模拟驱动可批处理跑完虚拟时段并输出 JSON 报告
