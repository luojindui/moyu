## 2. 55/55 图鉴最快路线

- 需求：**20,000 次累计点击**（66.7min@5cps）、6 个挂机项各 Lv.50（从 0 合计 **8.51e9**，其中 retire 7.22e9）、10 条语录（梗每 45-75s 一个，期望 **29.2min**、P90 44min）。
- 最快：纯挂机 **6.35h（381min）**；5cps 点击 **3.41h（204.7min）**。
- 集满的永久挂机 ×1.2 是**负收益陷阱**：白拿值 74min，但真去集满再冲终档反而更慢 —— 挂机 505.9min vs 445.5min（+60min）、点击 266.7 vs 244.2min（+22.5min）。

## 3. 捷径与节省时间

| 捷径 | 量化 | 节省 |
|---|---|---|
| `__MOYU__.rewindSave(28800)` + 刷新（生产 dist 也带） | 每次 +8h 离线收益（实测 +5760 = 0.2×28800，welcome 面板弹出），~2-3s/轮；151 轮到终档 | 225.6h → **7.6min**（30×）；按 10s/轮也只 25min |
| 合成 pointerdown / 自动点击器（无 isTrusted 校验） | 20cps 1.62h、100cps 16min、1000cps 1.8min | 省 5.8h ~ 7.4h |
| 巡逻/丢梗事件奖励 | 稳住巡逻 ≈ +5% 挂机收入（点击期 +1.9%） | 省 ~22min（②路线） |
| 日报 4 窗口/天（新功能） | 600×idleRate/次，7.4h 内最多 2 次 | <1min（奖励按当时 idleRate 算） |
| 回访效率 0.7→1.0 / 首日 1.0 | 只影响离线效率 | 对连续在线 0；对 rewind 刷：首日 1.0，之后 0.7 |
| 图鉴 ×1.2 | 见上 | 实际 −22 ~ −60min |

## 5. 问题清单（按严重度）

- **P0** 生产包暴露 `__MOYU__` 调试钩子：`rewindSave` 一键 8h 离线，终档 7.6min，任何竞速榜/成绩作废。
- **P1** 转生最优解退化：1e8 门槛 spam 134 次（>6h 同质重复、零路线决策），与"攒够再转"的留存设计意图相反；80% 等级保留让越刷越无痛。
- **P2** 点击无防护：合成 pointerdown（`e.isTrusted` 不校验、无 cps 上限）→ 自动点击器 1.6h、1000cps 1.8min。
- **P3** 打开日报时 rAF 降帧且丢弃 dt（收入约 1/3）；而转生又必须开日报 → 长时间停留面板会亏时间。
- **P4** 图鉴 ×1.2 在竞速语境是负收益陷阱（+22~60min），与"集满给奖励"直觉相反。
- **P5** 不转生路线 225.6h（9.4 天）看不到终档；转生层实际是必选项。

## 6. 建议（最多 3 条）

1. 生产构建移除 `__MOYU__` 调试钩子（或编译期 dev-only），否则 P0 无法验收。
2. 修转生 spam：转生点按"本局/当前倍率"折算，或对第 n 转加递增解锁阈值/冷却，把最优路线从"刷 134 次"压回"攒够再转 3-8 次"。
3. 点击加固：pointerdown 校验 `isTrusted` 或对 >10cps 折减/限频。
