## 2. 画面分析（像素数据）

**画布构成**：内容带 y196–492（占画布 53%）；地板 y492–694（202px = 画布 36% / 屏高 24%）。
**空白**：10×10 网格中 51% 单元格对比度 <8（视觉上接近纯色）；地板区 top2 颜色占 70.9%，只有砖缝和"戳屏幕摸鱼"提示字。
**配色**：场景代码使用 47 个固定 hex；渲染 top8 色占全画布 59.2%（地板棕 #5a4a3f 20.4%、墙蓝灰 #444864+#353b56+#3a3f5c 22%、木桌棕 8.5%、砖红 2.5%、窗蓝 3.3%、米色 2.3%、绿 0.9%）。
- 平均亮度 94/255（偏暗）、平均饱和 0.33、高饱和像素（max−min>90）仅 4.6%
- 高饱和点缀：红 3.0%、黄/金 2.45%、绿 1.1%、天蓝 6.5%、**粉/品红 0.0%**
- 暖/冷 ≈ 49%/45%，但"暖"几乎全是脏棕木色，不是暖光；无暖色光源（吊灯光 13% alpha）
- 元素：可见道具约 15 个，390px 宽下能一眼认出的只有窗、钟、公告板、桌、绿植、饮水机 6 个；主角 48×48px（占屏 1.1%）；地毯 50% alpha 几乎看不见；桌面文件/杯/键盘 16–30px 不可辨。

## 4. 三个装扮系统（按性价比排序）

### S1（性价比 #1）主题皮肤包 Theme Pack — 代价 2
- **解锁**：14 段段位每 3 段解锁 1 套（约第 1/4/7/10 段各一套）；转生点可买"限定主题"。
- **5 套具体**：① 奶油草莓（墙 #fff1f2 粉白、地板 #f5d9c4、窗帘 #ffb7c5、暖光、窗外樱花飘落）② 森系薄荷（墙 #e3f6ec、窗 #a8e6cf、绿植变多、窗台多肉）③ 深夜办公室（现有默认）④ 猫咪咖啡屋（暖棕+粉霓虹、墙贴猫爪/菜单板）⑤ 樱花祭（粉紫渐变墙+花瓣粒子）。
- **视觉变化**：一键换全屋配色 + 窗景 + 灯光色 + HUD 强调色，切换 0.4s 交叉淡入。
- **收集价值**：主题收藏册 5/5，集齐解锁「彩虹墙纸」；每个主题配称号（"粉红打工人"）可挂 HUD。
- **为什么先做**：现有 47 个 hex 全在 scene.ts 常量里，抽 palette 表即可，**一次改动全画面变化，截图一眼可见**；不需要新美术。

### S2（性价比 #2）工位摆件槽 Deco Slots — 代价 3
- **解锁**：4 个固定槽（桌面左/桌面右/墙面/地板中央）按累计摸鱼值 1e3/1e5/1e7/1e9 解锁；摆件由图鉴进度/点击里程碑/巡逻奖励掉落。
- **10 件具体**：猫爪杯、仙人掌、小恐龙玩偶、招财猫（2 帧招手）、迷你鱼缸（鱼游动）、照片墙（可换 3 张）、串灯（呼吸闪烁）、椅背蝴蝶结、抱枕堆、宠物窝。每件 3 种配色可换。
- **视觉变化**：直接画在 canvas 锚点（16–24px 程序绘制 + 少量 2 帧动画），可拖动换位。
- **收集价值**：摆件图鉴 10/10 + 稀有度 N/R/SR + 套装共鸣（凑齐桌面 4 件触发粒子），把"文字图鉴"升级成"看得见的收集"。
- **代价**：存档 deco 字段、图鉴/商店新 tab、场景绘制分支、掉落逻辑；无需外部美术。

### S3（性价比 #3）办公室宠物 Pet — 代价 4
- **解锁**：累计点击 500 得"猫咪蛋"，之后图鉴 10/25/40 各送 1 只；每日摸摸涨亲密度。
- **3 只**：三花猫（趴桌/伸懒腰/踩键盘）、仓鼠（跑轮/叼瓜子）、柯基（摇尾巴）。
- **视觉变化**：16×16 4–8 帧 walk/idle/睡觉；点击场景宠物冒爱心跟随手指跳；老板巡逻时躲桌下（与事件联动，有梗）。
- **收集价值**：宠物图鉴 + 配饰（围巾/帽子/铃铛）+ 亲密度等级 → 最想截图炫耀。
- **代价**：新 sprite 4–8 帧×3 只、行为状态机、交互与存档；成本最高，收益也最高（分享）。

## 5. 分享潜力评估

**现有可分享点**：几乎为零。唯一"可炫"是图鉴 55/55（纯文字列表，截出来是 55 个绿色文字块）、段位"宇宙尽头·终"、转生 ×18.63、连续天数——全是数字。
**缺失**：
1. 无分享入口（无 navigator.share、无截图/保存按钮、无明信片生成）
2. 无"看得见的收藏"（55 件全是文字，无卡片图/无稀有度/无陈列墙）
3. 场景静态，无稀有画面（事件是整屏色块，反而破坏构图）
4. 无"我的工位"标识（边框/水印/日期/称号），截图认不出是这款游戏
5. 无前后对比（第 1 天 vs 第 30 天工位）
**建议**：S1+S2 落地后加"一键工位明信片"（canvas 截帧 + 段位边框 + 日期 + 主题水印 + navigator.share/长按保存），分享给限定贴纸。

## 6. 总评

对女性向装扮收集玩家：**吸引力弱（3/10）**。当前是"数值挂机 + 夜班办公室"的硬核增量游戏，可爱元素只有挂钟/绿植/像素小人，且绿植像烟囱、饮水机悬空、事件是大色块；"看起来好看、有东西可换"两条都不满足。
数值层、图鉴文本（语录很懂打工人）、日报/段位/转生的留存骨架是 OK 的，可作底座。
**可交付：否**（针对本画像）。最低可接受改造：先做 S1 主题皮肤（代价 2）+ 修 11 项丑点里的 1/2/3/4/6/8/10；若只允许一项，做 S1。
