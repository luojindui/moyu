## 每日决策链实测

上线一次（每天 3 次开机，08:00 / 12:30 / 19:00，合计约 20 分钟）实际要做的东西：

| 环节 | 实录 | 是否决策 |
|---|---|---|
| 开机离线结算 | 自动弹欢迎面板，显示离线收益 | 否 |
| 每日摸鱼卡 | 3 选 1；16 张卡按日价值可从高到低固定排序（引擎实算：通宵摸鱼 6.29e8 > 老周的秘密 5.15e8 > 远程办公日 3.87e8 > 咖啡管够 2.32e8 …；部门搬家/HR 约谈/截止日逼近为**负收益**，只能"跳过"） | **是，但只是查表**：没有权衡，只有排序 |
| 每日精力 | 引擎枚举全部可行子集：最优恒为「认真摸鱼+专注点击」= 85/100 点（剩 15 点作废，比次优「摸鱼+假装+社交」+9~10% 日价值）。live 实测点完 `left=15, boosted.idleMult=1.35` | **否**：固定答案 |
| 日报 | 3 个目标里 2 个自动完成（上线/挂机），第 3 个硬核随手完成；每 6 小时领一次（3 窗/天） | 否 |
| 派遣 | 自动重复 + 开机自动领取；5 人最优全部派「楼下买咖啡 8h」（其余 5 个任务被支配） | 否（设置一次后 0 决策） |
| 家具/同事/天赋 | D1-D2 家具 8/8 买完、5 人招满并升到 5 级；D10 天赋 24 点满 | 否（一次性清单） |
| 摸鱼站 | 每天 3 次，满分合计 = 75 挂机秒 = 日收入 **0.02%~0.04%**（D5 之后）；对硬核=可跳过的内容 | 否 |
| 转生 | 30 天最优 = 每天开页面转一次（+20 点/次，29 次，倍率 ×430） | 否（固定节奏按按钮） |

**结论：每天真正需要"想一下"的决策 = 1 个（卡牌 3 选 1，且是固定排序）；其余全是领取/点击仪式。真正的取舍只存在于 D1-D3（先买哪件家具、先招谁、第一个任务派什么），之后全部收敛到唯一最优。**

## 最优策略与假选择清单

### 唯一最优（硬核 30 天实算）

1. **玩法级最优：少上线。** 关机画像 D30 生涯 2.83e16 vs 页面常开 1.69e16 → **关机多 68%**。原因：离线效率可自然 >100%（实测 D2 起 1.13，D3 起 **1.31**；带事件终极可达 **1.51**）——回访 3 次 +0.30、连签 3 周 +0.15、好感 40 +0.03、小美 +0.02 先把基数顶过 1.0，再由家具离线 +0.23、天赋 +0.08、事件终极 +0.20 抬高上限。**同样 1 小时，离线 1.31~1.51 倍收益；最优策略 = 上线 1-3 分钟做完领取/决策立刻关页面**（每段离线 ≤12h 以吃满封顶）。
2. **转生节奏：攒到接近单次上限（20 点）再转 ≈ 每天一次。** 30 天实算：每天转一次 2.83e16（100%）> 攒 20 点 1.86e16（65.9%）> 攒 10 点 1.26e16（44.7%）> 攒 5 点 4.02e15（14.2%）> 一解锁就转 1.59e15（5.6%）> 不转 3.55e13（0.1%）。「一解锁就转」每转一次把等级打回 80%，20min/天画像回补不及 → 反而低 94%。（长在线画像相反：上代竞速报告实测 spam 134 转 7.4h 打穿终档——**说明转生最优频率取决于在线时长，没有唯一策略，但两种都是按固定节奏点按钮**。）
3. **加点：** 挂机全（5a）+ 点击全（5a）+ 事件 t1-4 = 24 点（日价值 4.58e9，比次优 +23%）；被放弃的固定是事件终极。
4. **派遣：** 5 人全派 8h「楼下买咖啡」。
5. **精力：** 认真摸鱼+专注点击（85 点，浪费 15 点）。
6. **卡：** 按「挂机% > 离线% > 派遣% > 点击%」排序取最高；3 张全负就跳过。
7. **家具：** 全买（D1-D2 结束），顺序按回本（≈价格顺序，投影仪最后）。

## 剩余设计缺陷（P1/P2）

### P1（让硬核觉得无聊/假选择）

- **P1-1 离线效率可自然 >100% → 最优玩法是"别玩"。** 实测：D3 起 1.31（家具+天赋），带事件终极 1.51；关机 30 天 = 常开 1.68 倍。主动玩法（点击/巡逻/丢梗/小游戏/精力/卡）全被离线效率体系压制；这与"每天上线做决策"的设计目标直接冲突。建议：离线效率封顶 1.0（raise 只用于把 0.7 补回 1.0），或让 raise 只作用于在线。
- **P1-2 转生退化：** 30 天 29 次转生（×430 倍率）、段位 D3 打穿终档后被生涯累计甩开 88,000 倍；「攒够再转」与「spam」的胜负只取决于在线时长，无冷却/无递减/单次封顶 20，最终都退化成"按固定节奏点同一个按钮"。建议：递增门槛或按次数递减单次上限，并把段位/终档与转生点解耦。
- **P1-3 精力是假取舍且 UI 推荐次优：** 「4 项 145>100」只在两种画像下各有一个固定最优组合（关机=摸鱼+专注 85；常开=摸鱼+假装+社交 100），不存在分配；「省心组合」在硬核画像下 -9~10%。另外精力只在"当天在线+同日离线段"生效（夜离线跨日重置），后期离线占 80%+ → 该决策只影响约 5% 日收入。
- **P1-4 派遣：收益最高、思考最少。** autoRepeat+一键领取后每日 0 决策；6 任务在两种画像下都由 8h 咖啡支配，匹配/专长是假选择；派遣占日收入 12%~21%（设计目标 10-18%，晚段超上限），却是全自动的。UI 的「净 +X/小时」按"页面常开连续领取"计算，与关机玩家实际最优（8h 任务）矛盾，会误导。
- **P1-5 天赋"必须放弃一条流派"是固定解，且点击流名不副实：** 24 点最优唯一（挂机全+点击全 5a+事件 t1-4）；点击收入在 D5 后占比 0.00%，点击系天赋实际提供的是挂机%——三条流派实际是"一条挂机线 + 一条伪点击线 + 一条几乎无效的事件线"。
- **P1-6 家具是一次性清单：** 8/8 在 D2 完成，之后系统永久终结；离线两件/台灯/投影仪都是"画像陷阱"（特定玩法下 0 收益），UI 无任何条件提示。
- **P1-7 摸鱼站与放置经济脱钩：** 3 次/天恒定 75 挂机秒（0.02-0.04% 日收入），只在 D1 有意义；此后纯内容。对硬核玩家 = 可以永远不点。

### P2

- 段位 14 档 D3 打穿；D30 生涯 88,000 倍于终档，无任何新目标承接。
- 卡池 16 张里 3 张纯负收益（部门搬家/HR 约谈/截止日），只能靠"跳过"机制规避；剧情链只有 HR 约谈→秘密项目一条，30 天无后续叙事。
- 图鉴 55/55 与"最优解"冲突（需要买最差 ROI 升级）；后半段 +2%/5 格的收益在后期量级下可忽略。
- 好感 5 档 D19 满，之后社交精力 0 收益；「预警提前 1 秒」等里程碑在硬核操作下无感。
- 日报奖励 max(500,600×挂机秒) ×3 窗/天 ≈ 日收入 1-2%，是"登录税"而非决策。
- 离线效率 131%/151% 在日报 UI 直接显示但无解释；玩家看不出"关页面更赚"。
- 页面常开时「离线系」内容全部归零（地毯/按摩椅/离线卡/离线天赋/离线段位加成），而这是最常见的挂机党玩法。
- 生产包已剥离调试钩子（已确认），但 dev 的 `grant/endMissions/forceBoss` 任意可见——验收环境与生产一致，OK。

## 整体判断 + 可交付：是

**四批系统本身都做完了，而且是"好实现"：** live 全流程无阻塞——招募/升星/派遣/自动重复/一键领取、18 天赋节点点亮、8 件家具购买与场景绘制、4 项精力（live 实测摸鱼+专注 left=15、idleMult=1.35）、3 选 1 卡牌（16 张，含跳过）、回合制老板（读线索选应对，live 实测选对 +36723）、摸鱼站 3 个小游戏（找老板 30 秒无限轮计时正常）、日报/图鉴/转生面板全部可用；控制台 0 错误；线上 v0.5.0 与 dev 一致、无调试钩子。

**但"从点屏幕变成有策略"这个目标只完成了一半：** 游戏从"纯点击"变成了"有一张 2 天耗尽的清单 + 每天 1 次卡片查表 + 一个转生按钮"，**没有产生需要权衡的决策**。所有系统在 1-3 天内收敛到唯一最优；D10 后硬核玩家的最优操作是「上线 1 分钟 → 关页面等离线」（离线效率 131% 比在线高 31%），这与"每日决策链"的宣称相反。真正的"长线"只剩图鉴最后 3 格和数字增长；段位系统 D3 即死。

- **可交付：是**（功能完整、无 P0、线上一致、稳定可玩；对休闲/收集/碎片玩家是一款合格的放置游戏）。
- **但若验收目标是"硬核玩家能玩 30 天不无聊"：否。** 策略深度 3/10、长线内容 3/10、硬核推荐 3/10；建议下一轮优先修 P1-1（离线效率封顶）与 P1-3/P1-4（让精力/派遣真正产生取舍），否则加多少系统都会被硬核玩家在 D3 看穿。

**Chrome 清理确认：** 所有 CDP 探针均通过 [chrome.mjs](playtest/lib/chrome.mjs) 的 `runChrome()` 启动（随机端口、finally 中 SIGKILL + 删除临时用户目录）；两次 live 探针结束后已确认**我的探针 node 进程 0 个、无 chrome 进程残留**，并清理了我产生的 4 个残留临时目录。当前 `/tmp` 下仍有 chrome 临时目录属于**并行其他 agent 正在运行的探针**（`r16-*`、`final-audit/probe-prod.mjs`、`probe-final-data-cdp.mjs` 等），未动。本报告结束后我方 Chrome 已无残留。
