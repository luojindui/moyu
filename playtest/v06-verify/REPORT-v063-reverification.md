- **2 分钟留存：8/10**（v0.6.0 是 6，v0.5 是 5）
  目标条**从 0 秒到走完一次都没消失**（两局在完成前的 57/60 帧里 **0 帧隐藏**），9 步依次推进：戳→首购咖啡→攒钱→买刷手机→等挂机→选卡→领日报工资（+792）→**招募老周（新人价 1,500）**→分配精力→玩一局摸鱼站（30 秒真游戏）。**两局都在 87.3s / 91.8s 自然走完全部 9 步**，角标在完成瞬间按时解禁（🎮"2"/天赋/精力 60，各 1 个、无重复）。
  扣分：领工资后到招募之间要**干戳约 28 秒**攒 700（目标条进度恒 0%）；以及日报第三目标随机性带来的潜在卡步（见下）。

- **系统过载（越低越好）：6/10**（v0.6.0 是 7，v0.5 是 8）
  首分钟只有"点击+商店"一个系统，角标全藏；46 秒后进 👥 时是三 tab 墙，但这次有明确目标（新人价 1,500 可完成），负担比之前小。余下：📔 因成就墙仍有 1500+ 字；天赋/工位 tab 内容仍在。

## 第几秒会删

**正常随机下：前 2 分钟不会删——从"删"变成"再玩一天"。**
最接近删的时刻是**第 26–56 秒**：领完工资余额 815/837，招募要 1,500，目标条进度恒 0%，要干戳约 28 秒（我 2.4 下/秒、点击力 11 用了 28 秒；真实手速/点击力低的话要 40–90 秒）——手会酸，但数字在涨，会继续。

**最差随机下：第 30 秒想删。** 日报第三目标随机池仍含「老板巡逻时忍住不点，1 次」（`daily.ts` 的 `survive_2`）。弃坑型第一次遇到回合制老板 2/3 概率答错（新手保护不扣钱，但目标不算），要等下一次巡逻（90–150 秒）才能领工资 → 目标链卡在领工资步 1.5–2.5 分钟。本次两局都随机到「买 3 次升级」没触发；v0.6.0 我实测到 click_100 卡 20.3s、meme_1 卡 7.5s，survive_2 更糟。

## 剩余会删点（按严重度）

1. **P1-a｜招募存钱空档 28-29 秒，目标条 0% 无进度**：领工资 792 后余额 815/837，招募 1500，要再攒 ~700；期间目标条只写「招募第一位同事（新人价 1,500）」、进度 0%。建议目标条加「还差 685 / 再戳 30 下」或把招募按钮挪到 HUD 提示。
2. **P1-b｜日报第三目标随机到「巡逻忍住 1 次」时，领工资步可能卡 90-150 秒**（弃坑型老板题大概率答错）。最小修：**首日日报池去掉 survive_2**（或首日第三目标固定「买 3 次升级」，或老板题给正确答案提示）。
3. **P2｜46 秒后的 👥 仍是三 tab 墙**（虽然这次有 1,500 可完成目标，负担下降）。
4. **P2｜📔 成就墙让日报到 1500+ 字**（领工资在顶部不挡，但内容更多）。
5. **P3｜首屏「×2差5级」、10px 小标签**；未修：大额"再点确认"、📔 滚动后 ✕ 移出视口（lead 已记录）。

## 最小改动（若还要再收一轮）

1. 招募步进度提示：目标条显示「还差 X / 再戳 N 下」；或领工资后直接把余额补到 1,500（例如首日工资下限抬到 1,500）。
2. 首日日报池去掉 `survive_2`（或首日固定 `buy_3`），消除随机卡步。
3. 成就墙在 📔 里默认折叠。
