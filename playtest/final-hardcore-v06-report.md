## 复验① 离线 95% 上限：**收益关系已反转，通过**

**引擎实测（dev live，非模拟）：**
| 画像 | 离线效率 | 12h 离线 / 12h 在线 |
|---|---|---|
| 低回访（0 次回访） | 0.70 | 0.700 |
| 低回访（1 次） | 0.80 | 0.800 |
| 连签 7 天 | 0.85 | 0.850 |
| 满配（回访3+连签21+全家具+天赋 idle_4/事件5b+小美） | **0.95（硬上限）** | **0.475**（同事部分只按 50% 进离线，所以实际远低于 1） |
| 首日（建档 <24h） | 0.95 | — |

全部 <1，且 12h 离线收入始终低于 12h 在线（满配时 1.05e7 vs 2.20e7）。

**30 天模拟（同样玩法、仅"关机 vs 常开"不同）：**
- 每天关机：D30 生涯 2.58e16、挂机 3.41e10/s、离线效率 0.95
- 页面常开 24h：D30 生涯 **3.33e16**、挂机 4.16e10/s
- **常开 = 关机的 1.29 倍（+29%）**；旧版 v0.5 是"关机多 68%" → **反转成立，P1-1 已修复**。
- D30 状态单段 12h 公平对比：离线/在线 = 0.776（同事部分折半导致比 0.95 更低）。

**⚠ 修复带来的新问题（本轮新 P1，建议下轮修）：**
95% 硬上限让所有「离线效率 +X%」变成死内容。认真玩家 raw = 0.7+回访0.3+连签0.15+好感0.03+小美0.02 = 1.20，**本来就超过 0.95** →
- 引擎实测（回访3+连签21）：带全套家具/天赋/idle_4/事件终极 与 裸状态，**离线效率都是 0.95，离线加成收益 = 0**；只有低活跃玩家（0.80→0.95）才有意义。
- 失效内容共 6 处：**毛绒地毯（整件失效）**、**按摩椅（整件失效）**、小美被动、天赋 idle_4、事件终极的离线 +0.2、卡「提前下班/食堂加菜」；其中地毯/按摩椅是**花钱买 0 收益**，UI 仍写「离线效率 +5%/+8%」→ 新玩家陷阱。
- 建议：把离线加成改成「离线收入直接 +X%」，或在 0.95 上限内先加速到顶、溢出部分转成离线收入加成。

## 复验② 成就墙：**部分通过（22 条/10 分类是真的，但长线作用有限，且有 2 条永远拿不到）**

**UI/功能（live 实测）**：22 条、10 分类、`x/22 · Lv.y` 汇总、分类进度 chips、逐条进度条均正常；D1 完成 9/22、D2 14/22、D3 16/22、D5 17/22、D26 18/22（30 天）；线上已部署、控制台 0 错误。

**永久加成（引擎实算）**：30 天达成 18 条 → 挂机 **×1.511（+51%）**、点击 ×1.092；全可达 20 条 → 挂机 **×1.632（+63%）**。但 **D2 就有 14 条/挂机×1.47** → 成就墙本质是"早期加速器"，不是长线目标（D10→D30 自然只多 1 条：键盘杀手 D26）。

**D10 之后还能做的真实成就 = 3 条**：
- 键盘杀手（累计点击 10,000）→ 本画像 D26；
- 全图鉴（55/55）→ 需累计 2 万点击（约 D54 自然到达，或刻意 2.2 小时狂点）；
- 鼠标终结者（累计点击 100,000）→ 需 11 小时点击（约 267 天自然到达）→ 纯长线刷。

**2 条数学上永远无法完成（P1 逻辑 bug）**：
- `rank_14「宇宙尽头 达到第 14 段位」`：进度用 `rankIndex`（0 基，最大 13）< target 14 → **永远差 1**（描述与 target 差 1，应为 index 13）；
- `talent_18「天赋满树 解锁 18 个天赋」`：天赋点上限 24，18 节点需 27-36 点；引擎穷举 24 点最多 14 节点 → **永远差 4**；
- ⇒ 成就理论上限 **20/22（Lv.6）**，收集党永远无法全成就。

**其它发现**：
- 「每 4 条 = 1 成就等级」的等级**只用于 UI 展示**（achLevel 仅 journal.ts 引用，不参与任何收益）→ 假进度条；真实收益全在单条成就的永久乘区。
- **进度倒退**：boss_3/boss_10 用「当前连胜 surviveStreak」，而转生会把它清零 → 每次转生后这 2 条成就"掉线"、+6% 挂机暂失，需再安然巡逻 10 次恢复；天赋免费重置也会让 talent_6 掉线。成就进度应取历史最高。
- 性能修复实测：首 5 连点总耗时 **5.2ms**（音频预热生效，旧版首点 143ms）；FPS 稳定 60；DPR2 下帧数正常。

## 剩余 P1 / P2

**P1（新增/未修）**
1. **【新】离线加成内容全部失效**：95% 上限下，认真玩家 raw=1.2 已超上限，6 处「离线效率+X%」内容收益归 0（地毯/按摩椅整件变 0 收益陷阱、小美、idle_4、事件终极离线、离线卡）。建议改乘区或 cap 内溢出转收入。
2. **成就 2 条永不可达**：rank_14（0 基索引差 1）、talent_18（24 点上限 vs 18 节点需 27+）→ 全成就/满级不可能。
3. **成就等级是假进度条**（只 UI 展示），且成就墙 17/22 在 D5 前拿完，D10-D30 只多 1 条 → 仍未解决"D10 后没事干"。
4. **老板成就进度会倒退**（用当前连胜，转生清零）；天赋重置同理。
5. **转生节奏/段位 D3 打穿未修**（自认未做）：最优仍是"每天转一次按钮"（29 次 → ×430），spam 在 20min/天画像下 -94%；长在线画像相反 → 无唯一策略、无取舍。
6. **派遣/精力/天赋/家具仍是假选择**（上轮 P1 未动）：派遣 8h 咖啡单一最优+全自动+占日收入 13-23%；精力唯一最优「摸鱼+专注」85 点，UI「省心组合」仍次优 -9~10%；天赋唯一最优（放弃事件终极）；家具 D2 买完清单。

- **复验①通过**：离线 95% 上限真实生效（引擎+live 双验证，全部 <1），"关页面等离线"的最优已反转（常开 +29%），旧 P1-1 修复。

- **可交付：是**（无 P0；离线上限与成就墙都上线且线上 v0.6.0 一致；性能修复实测有效）。建议下轮优先修：①离线加成乘区化（新 P1）②achievements 的 rank_14/talent_18 target ③老板成就改历史最高 ④成就墙补 D10+ 目标（例如"转生次数/总挂机时长/单日收入"类里程碑）。
