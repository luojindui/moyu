- 试玩版本：dev `http://127.0.0.1:5173/`（2026-11-27 19:09，APP_VERSION 0.4.0；本轮试玩期间有并行 a11y 改动加入「一键全用」，引擎数值文件 `decor.ts`/`energy.ts` 未改动）；线上 `https://luojindui.github.io/moyu/` 已部署批次 3（无「一键全用」）。
- 方法：全部数值由引擎函数计算（`effectOf`/`clickPowerOf`/`offlineEarn`/`offlineEfficiency`/`dispatchReward`/`bossSurviveReward`/`useEnergy`/`buyDecor`），进度状态由「按 ROI 贪心买升级/同事」的自融资模拟推进到每件家具**首次买得起**的时刻（不猜）。
- 证据：`playtest/r14-hardcore-evidence.json`、`playtest/r14-hardcore-evidence.txt`、`playtest/r14-hardcore-live.json`、`playtest/r14-hardcore-decor.png`；探针 `playtest/probe-r14-hardcore.ts`、`playtest/probe-r14-live.mjs`。
- 画像基线（ROI 主表）：标准混合＝在线 2h/天、点击 20min/天@2.5cps、自动派遣；每天首次开机结算 12h 离线（引擎算出离线效率 0.90）。另跑纯挂机、点击党、硬核常开（挂机页全天开）三种画像做敏感性。

排序结论：**绿萝 < 地毯 < 冰箱 < 按摩椅 < 台灯 < 鱼缸 < 猫窝 < 投影仪**（混合日模型）≈ 价格顺序。全部为一次性买断，回本 ≤ 1 天（除投影仪按 2h/天口径 1.8 天）；**没有「明显坑」①**（全部正收益），也**没有「唯一最优」**——8 件全部最终会买，唯一决策是顺序。

**决策频率判断（问题 3）**：两套系统都**没有**给出「每天要想一下」的决策。家具是 8 条一次性待勾清单（约 2–3 天内买完，之后永不再考虑），且策略答案固定：按「回本/价格」从便宜到贵买，而不是无脑买最贵（投影仪最贵之一但 ROI 最差）；精力则是无脑全点（现在甚至一键全用）。唯一需要「想一下」的是三个一次性判断：①页面常开/离线封顶后别买地毯与按摩椅；②不点击就别买台灯；③不派遣就别买投影仪——都不是每日决策，且 UI 不提供任何提示。

打包：8 件总价 22.35 亿，全买齐 = 工位挂机 ×1.435（+43.5%）、点击 ×1.265、离线 +23%、派遣 ×1.3。在猫窝首次可买时点，整套只值 **3 小时当前收入**，而同时间升一级升级要 24.5h 回本 → 终局家具是最划算的消费（升级 ROI 已崩塌）。

注意：「挂机 +X%」只放大**工位**部分（不含同事固定/占比）。末期工位占总挂机 76–80%，所以「猫窝 +15%」实际只带来总收益 +11~12%；同理经历其它家具。

① 「坑」只在条件态成立：地毯/按摩椅在离线效率封顶或页面常开时收益恒为 0；台灯/投影仪在「不点击/不派遣」画像下恒为 0（引擎实测 Δ=0）。

## 精力最优分配分析

**结论先说：现行预算下无「分配」可言——100 点恰好等于三项总和（40+35+25），最优解恒为「全部使用」。**

引擎实测（`useEnergy`）：slack→剩 60、fake-work→剩 25、social→剩 0；第 4 次返回 null。Live 实测：依次点完三项后 `left 0/100`、`used=["slack","fake-work","social"]`、`boosted={idleMult:1.25, patrolRewardMult:1.8}`（无异常）。且本轮 dev 版 UI 已直接提供「**一键全用（3 项，共 100 精力）**」并写明「3 项合计正好 100」——等于产品自己承认无取舍；而 `energy.ts` 注释写的设计目标是「给每天一次资源分配的决策」，目标未达成。

每点价值（引擎口径；slack 含 12h 离线结算，fake-work 按在线 2h×60 次巡逻×变体均值 1.22，social 为 0→100 好感的终局价值摊到 34 天）：

| 时点 | 认真摸鱼（40 点） | 假装工作（35 点） | 跟同事聊天（25 点） | slack : fake : social |
|---|---|---|---|---|
| 早期 D1（工位占比 32%） | 4,315/点 | 892/点 | 131/点 | 33 : 6.8 : 1 |
| 中期 D7（工位占比 73%） | 616,356/点 | 47,106/点 | 2,884/点 | 214 : 16.3 : 1 |
| 后期 D30（工位占比 80%） | 8,928,036/点 | 621,347/点 | 71,024/点 | 126 : 8.7 : 1 |

slack/fake 绝对倍数：4.8× / 13.1× / 14.4×。原因是巡逻收益本身只有挂机收入的 ≈6.1%（4×挂机秒×30 次/h×连胜 1.5×变体 1.22 ÷ 3600×挂机秒），+80% 仅 = 在线挂机收入的 +4.9%；而 slack = 工位 +25% ≈ 总收入的 +18~20%。

**是否存在唯一最优？存在，且与画像无关**：slack ≫ fake-work ≫ social，三档状态一致。唯一例外是「完全不升任何挂机升级的极端纯点击号」：此时挂机率只有底薪 0.2/s，巡逻奖吃 50 地板价 → fake-work 4,392/天 > slack 360/天（12×），但两者都只是点击收入的零头，不构成策略分歧。
稀缺预算反事实（预算 < 100 只能三选二）：三档状态最优均为 slack+fake-work；即固定排序 slack > fake > social。

补充：social 的 +3 好感被自身系统架空——派遣领奖每次 +2（匹配任务 +3），3 分钟任务 ≈ 20 次/小时，1 小时派单就顶 +40~60 好感；+3/天 只相当于 1~1.5 次领奖。且满 100 后永久 0。

## 被支配选项清单

1. **假装工作（精力，35 点）** — 每点价值恒为「认真摸鱼」的 1/4.8~1/14.4，离线收益为 0。若预算稀缺永远不选；现在只因为「预算=总和」才被白送。
2. **跟同事聊天（精力，25 点）** — 无同事时 0；全员好感 100 后永久 0；+3/天 ≪ 派遣领奖的 +2~3/次；价值集中在 40/60/80/100 四个门槛日，其余天数边际为 0。任何画像下都不是优先项。
3. **按摩椅（400 万）** — 与毛绒地毯同一条「离线效率加算」线，价格 33×、单位效率价格 20.8×；先买地毯后边际只剩 +3%（≤+0.03），封顶/常开时为 0 → **永远不该买**（除非纯收藏）。
4. **毛绒地毯（12 万）** — 页面常开玩家 = 0（无离线结算）；离线效率封顶后 = 0（第 1 天恒 1.0；连签 3 周 0.15 + 回访 1 次 0.1 + 好感 40 的 +0.03 + 小美 +0.02 + 基础 0.7 = 1.000）。只有「前 3 周会关页面」的玩家值得买。
5. **护眼台灯 / 投影仪（画像支配）** — 不点击：台灯 Δincome=0（引擎实测）；不派遣：投影仪 Δ挂机=0、Δ派遣=0。属于「画像内永远不选」，不是绝对支配（点击党/派遣党很值）。
6. **「三选一」本身** — 无互斥、无上限惩罚、预算刚好够三项 → 选择不存在，本质是每日登录税。

## 问题清单（P0/P1/P2 + 证据）

**P0-1 精力是伪决策：100 = 40+35+25，最优恒为全点。**
证据：`useEnergy` 三连后 left=0、第 4 次 null；live `energy.left 0/100`、三项全勾；dev UI 直接给「一键全用（3 项，共 100 精力）」+「3 项合计正好 100」。与 `energy.ts` 注释「每天一次资源分配决策」的设计目标相悖。

**P0-2 精力「效果持续到当天结束」被违反：昨日 buff 会结算进今日离线收益。**
证据：boot 顺序为 `settleReturn`（main.ts:76-79）在前、首帧 `ensureEnergy`（main.ts:641）在后，`restore`/save 保留旧 `boosted`（save.ts:274-283 不做跨日清空）。用 save→restore→settleReturn 复现：12h 离线结算，带昨日 slack = 2.97e8 vs 无加成 = 2.64e8（**+12.5%**）。→ 「认真摸鱼」实际可变成「睡前点一下的永久离线加成」。

**P1-1 离线效率 100% 封顶可自然达成 → 两件离线家具收益归零。**
证据：`offlineEfficiency = min(1, 0.7+回访0.3+连签0.15+好感0.03+小美0.02)`；第 1 天恒 1.0（`FIRST_DAY_MS`）。引擎实测（12h 离线）：D22+小美+好感40 状态，地毯/按摩椅/两件增量 = **0 / 0 / 0**（价格 12 万 / 400 万）；D8 时为 +0.05/+0.08/+0.10。UI 无任何「可能为 0」提示。

**P1-2 按摩椅被毛绒地毯支配**（同上一条实验）：同一条加算线、价格 33×、单位效率价格 20.8×；买地毯后边际 ≤+0.03，封顶/常开 =0。

**P1-3 假装工作被认真摸鱼全面碾压**：每点价值 1/4.8~1/14.4（引擎三档状态），且有离线 0 收益；若真要「三选一」它是恒定次优项。

**P1-4 跟同事聊天价值近乎为零**：无同事 0 / 满 100 永久 0 / 相比派遣领奖可忽略 / 收益阶梯式大部分天数为 0。

**P2-1 离线结算口径 bug：工位倍率（家具/今日卡/精力）在离线只按 50% 计入。**
`offlineEarn` 以 `stationIdleScaled()`（不含家具/卡/精力倍率）为「工位 100%」基数，把这三类倍率误划入「同事部分」再 ×0.5。实测绿萝 +5% 在 12h 离线拿到 2.91e6，应为 5.83e6（**50%**）。影响 plant/fridge/aquarium/catbed 的离线部分与 slack 的离线部分。

**P2-2 顺带发现（批次 2 天赋）：idle_4「离线效率上限 +0.08」是永久无效节点。**
`offlineEfficiency` 把 `talentBase` 同时加到 `min()` 的两端（上限 1+talentBase、基数 0.7+talentBase+…），数学上恒抵消；event_5b 的「离线效率 +0.2」同理。实测 D22+小美+好感40：无天赋 0.95/1.00、有 idle_4 1.03/1.08，可填补缺口始终 = 一个地毯的量；地毯收益仍为 0 → 天赋并不能拯救离线家具。

**P2-3 家具 UI 不显示单件增量/回本/前置条件**，只显示叠加总倍率（「已装修 x/8 · 挂机 ×1.43」）；「挂机 +15%」实际是工位 +15%（末期 ≈ 总收益 +11~12%）；玩家无法判断值与不值，也不知道地毯/按摩椅可能为 0。

**P2-4 投影仪快照机制**：派遣奖励在派单瞬间快照，买投影仪对已在执行的任务无加成；且派遣只在开页面时结算 → 每天只开 2h 的玩家回本 43.7h（全家具最差），买了没有即时反馈。

**P2-5 价格/效果曲线不匹配**：价格 3k→20 亿（66.7 万×）只换效果 5%→15%（3×）。靠「升级 ROI 后期崩塌」才让末期家具划算（猫窝时点：升级 24.5h vs 整套家具 3h 回本）→ 隐性最优策略是「晚买 / 别急着买」，与「看得见的成长」意图相冲突。

**P2-6 无排他、无分支、转生保留**：8 件全部可买可叠加 → 没有 build 选择，只有购买顺序；对硬核玩家 = 8 条待勾清单 + 一个每日按钮。

**P2-7 精力无结转/无兑换**：未用完即作废 → 每日登录税（缺勤惩罚）；加入「一键全用」后进一步退化为纯仪式。

## 可交付：是（技术可交付，但作为「策略系统」不达标）

- 是：购买/使用/存档/转生保留/场景绘制/面板交互全部闭环，live 无 console 异常，数值无失控（全部家具正收益、无刷钱漏洞）。
- 但两套系统都没有产生任何取舍：家具＝8 条一次性待勾清单（且其中 2 条可在封顶/常开后变成 0 收益），精力＝每日固定全点的登录税。建议 P0 让精力产生真取舍（预算降到 60–75，或互斥/额外解锁消耗），P1 修离线封顶与地毯/按摩椅定价（或改成其它乘区）、给 fake-work 独立价值或删除。
