# 批次 3 规格：工位经营 + 每日精力

> 实现：`src/engine/decor.ts`、`src/engine/energy.ts`、`src/render/scene.ts`（drawDecor）、`src/ui/team-panel.ts`（工位 tab）

## 一、工位经营（8 件家具）

| 家具 | 价格 | 加成 | 场景表现 |
|---|---|---|---|
| 绿萝 | 3,000 | **工位挂机** ×1.05 | 左下花盆+叶簇 |
| 护眼台灯 | 20,000 | 点击 ×1.15 | 桌面右侧灯杆+灯罩+光锥 |
| 毛绒地毯 | 120,000 | 离线 +5% | 桌下半透明地毯 |
| 迷你冰箱 | 600,000 | **工位挂机** ×1.08 | 左下冰箱（把手/分层） |
| 按摩椅 | 4,000,000 | 离线 +8% | 桌子右侧椅背+坐垫 |
| 鱼缸 | 30,000,000 | **工位挂机** ×1.1、点击 ×1.1 | 右墙上方鱼缸+两条鱼 |
| 投影仪 | 200,000,000 | 派遣 ×1.3 | 天花板机身+镜头+地面光斑 |
| 工位猫窝 | 2,000,000,000 | **工位挂机** ×1.15、离线 +10% | 桌下猫窝+会摆尾的猫 |

规则：
- 购买扣余额；不可重复买；钱不够不可买
- **集齐 8 件完成奖励：永久工位挂机 ×1.1**（额外，非单件加成之和）
- 注意：家具的「挂机 +X%」只作用于**工位挂机**（不含同事固定产出）；同事占挂机比高时，实际总收益增幅会低于标称值
- 效果分别接入：挂机（`upgrades.effectOf`）、点击（`actions.clickPowerOf`）、离线（`progression.offlineEfficiency`）、派遣（`team.dispatchReward`）
- 存档：只接受已知 id、去重；**转生保留**（看得见的成长不清零）
- **离线效率硬上限 95%**（`OFFLINE_MAX=0.95`）：家具/天赋/卡的离线加成帮你更快摸到上限，但**永远不会超过在线收益**
  - 设计原因：旧版离线可到 131%~151%，导致"关掉页面等离线"成为最优玩法（比常开多 68%）
  - 首日基础效率 100% 同样受 95% 上限约束（但仍高于 70% 基准）
- 场景绘制位置按画布高度自适应（桌面横屏也不越界；矮屏鱼缸左移避开公告板）
- 台灯画在桌面**左侧**（效果文案未指定左右，以代码为准）

## 二、每日精力

- 每天 **100 点**，跨日重置
- **4 种行为**（合计 145 点 > 100 → 每天必须放弃至少 1 项，不能全点），**同日不可重复**：

| 行为 | 花费 | 效果 |
|---|---|---|
| 认真摸鱼 | 40 | 今天挂机 ×1.25 |
| 假装工作 | 35 | 今天巡逻奖励 ×2.2 |
| 跟同事聊天 | 25 | 全体好感 +5，且今天挂机 +5%（无同事时不可用） |
| 专注点击 | 45 | 今天点击力 ×2，且挂机 +8% |

- 最省的三项 = 25+35+40 = 100（恰好用完），第 4 项必然放弃 → 真实取舍

- 效果持续到当天结束（跨日随精力重置清空；**离线结算前先重置**，昨天的加成不会算进今天离线）
- **首日**：基础离线效率本就是 100%，但家具/天赋/卡片的离线加成**仍会叠加生效**（不被 1.0 截断）
- 存档 `boosted` 不信任存档值，**由 `used` 重新推导**（防"没用品却拿满档"）
- 存档净化：date 正则、left 0-100、used 去重且合法、boosted 钳制在 [1,2]/[1,3]
