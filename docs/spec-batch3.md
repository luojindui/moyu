# 批次 3 规格：工位经营 + 每日精力

> 实现：`src/engine/decor.ts`、`src/engine/energy.ts`、`src/render/scene.ts`（drawDecor）、`src/ui/team-panel.ts`（工位 tab）

## 一、工位经营（8 件家具）

| 家具 | 价格 | 加成 | 场景表现 |
|---|---|---|---|
| 绿萝 | 3,000 | 挂机 ×1.05 | 左下花盆+叶簇 |
| 护眼台灯 | 20,000 | 点击 ×1.15 | 桌面右侧灯杆+灯罩+光锥 |
| 毛绒地毯 | 120,000 | 离线 +5% | 桌下半透明地毯 |
| 迷你冰箱 | 600,000 | 挂机 ×1.08 | 左下冰箱（把手/分层） |
| 按摩椅 | 4,000,000 | 离线 +8% | 桌子右侧椅背+坐垫 |
| 鱼缸 | 30,000,000 | 挂机 ×1.1、点击 ×1.1 | 右墙上方鱼缸+两条鱼 |
| 投影仪 | 200,000,000 | 派遣 ×1.3 | 天花板机身+镜头+地面光斑 |
| 工位猫窝 | 2,000,000,000 | 挂机 ×1.15、离线 +10% | 桌下猫窝+会摆尾的猫 |

规则：
- 购买扣余额；不可重复买；钱不够不可买
- 效果分别接入：挂机（`upgrades.effectOf`）、点击（`actions.clickPowerOf`）、离线（`progression.offlineEfficiency`）、派遣（`team.dispatchReward`）
- 存档：只接受已知 id、去重；**转生保留**（看得见的成长不清零）

## 二、每日精力

- 每天 **100 点**，跨日重置
- 3 种行为，**同日不可重复**：

| 行为 | 花费 | 效果 |
|---|---|---|
| 认真摸鱼 | 40 | 今天挂机 ×1.25 |
| 假装工作 | 35 | 今天巡逻奖励 ×1.8 |
| 跟同事聊天 | 25 | 全体同事好感 +3 |

- 效果持续到当天结束（跨日随精力重置清空）
- 存档净化：date 正则、left 0-100、used 去重且合法、boosted 钳制在 [1,2]/[1,3]
