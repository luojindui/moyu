# 批次 5 规格：成就墙（长线目标）

> 实现：`src/engine/achievements.ts`（纯逻辑）、`src/ui/journal.ts`（成就墙渲染）

## 总览
- **22 条成就 / 10 个分类**，每条完成后给**永久加成**（挂机/点击/离线）
- 累计完成数 = 成就点数；**每 4 条 = 1 成就等级**，等级本身也给挂机加成（每级 +2%，避免"假进度条"）

## 成就列表（按分类）
| 分类 | 成就（目标） |
|---|---|
| 点击 | 手速入门 1,000 / 键盘杀手 10,000 / 鼠标终结者 100,000 次 |
| 挂机 | 躺平起步 1,000/秒 / 摸鱼自由 100 万每秒 |
| 图鉴 | 收集癖 20 / 博物学家 40 / 全图鉴 55 格 |
| 工位 | 开始装修 3 件 / 工位大户 8 件 |
| 小队 | 第一个同事 1 / 满编小队 5 / 资深团队 任一 5 级 |
| 天赋 | 初窥门径 6 / 天赋满树 **13**（24 点数可达上限） |
| 段位 | 中层摸鱼 7 / 宇宙尽头 **14**（最高档） |
| 摸鱼站 | 街机新手 500 分 / 街机高手 2,000 分 |
| 摸鱼卡 | 今日宜摸鱼 累计选卡 5 次 |
| 老板 | 老油条 连胜 3 / 摸鱼之王 连胜 10（用**历史最高**连胜，转生不清） |

## 状态字段（新增，含净化）
- `bestIdleRate`：历史最高挂机/秒
- `rankIndex`：历史最高段位（**1 基**，1..14）
- `cardsChosenTotal`：累计选卡次数
- `bestSurviveStreak`：历史最高巡逻连胜

## 设计意图
- 收集党：给"可刷的清单 + 进度条 + 永久收益"
- 长线：22 条覆盖早中后期；D10+ 仍有键盘杀手/全图鉴/鼠标终结者等长期目标
- 关键约束：**每一条都必须数学可达**（target 不能超过系统上限）
