# 批次 4 规格：摸鱼站（小游戏）

> 实现：`src/engine/minigames.ts`（纯逻辑）、`src/ui/arcade.ts`（DOM UI）、入口右下 🎮

## 总览
- 3 个 30 秒小游戏，**每天共 3 次**（跨游戏共享次数），跨日重置
- 奖励 = `floor(挂机收益/秒 × 25 × min(1, 分数/600))`：**满分 ≈ 25 秒挂机收益，跨阶段恒定**（旧公式含固定 +20，早期曾达 300 倍、后期 0.5 倍）
- 0 分也消耗次数；**中途退出（Esc/关闭）也消耗次数**（按当前分数结算，防"重开刷分"）
- 最高分记录在存档；**破纪录有「🎉 新纪录」提示 + 旧值对比**

| 游戏 | 玩法 | 计分 |
|---|---|---|
| **接咖啡** | 咖啡从上方掉落，点屏幕接住（时间窗 ±0.32s、横向 ±0.13） | 接住 +10，连击最高 ×2，漏接 -2 |
| **找老板** | 3×3 脸里找出王总（红色「王」），**30 秒内无限轮** | 正确 +50、错误 -20 |
| **节奏点击** | 120 BPM 节拍，跟着点 | perfect(±80ms) +20、good(±160ms) +10，perfect 额外 +5 |

## 存档净化
- `arcade.date` 正则、`played` 钳制 0-3、`best` 只接受已知游戏 id 且分数 ≤9999
- 转生保留（最高分不清）

## 无障碍
- 面板 `role=dialog aria-modal`、关闭按钮 44px、Esc 可关
- 小游戏全程可点（无拖拽），按钮 ≥44px
