# 批次 4 规格：摸鱼站（小游戏）

> 实现：`src/engine/minigames.ts`（纯逻辑）、`src/ui/arcade.ts`（DOM UI）、入口右下 🎮

## 总览
- 3 个 30 秒小游戏，**每天共 3 次**（跨游戏共享次数），跨日重置
- 奖励（**v2 实际实现**）：
  - `ratio = min(1, 分数/该游戏参考分) × 时长系数`
  - 各游戏参考分（打满口径）：**接咖啡 540 / 找老板 1200 / 节奏 1180**（按各自可达上限归一化，避免某游戏结构性打不满）
  - 时长系数：玩满 ≥1/3 时长（≥10s）→ 1；不足则按 `已玩秒/10` 线性折算（**防开局即退**）
  - 奖励 = `max(floor(挂机/秒 × 25 × ratio), ceil(30 × ratio))`（三游戏打满都 ≈ 25 秒挂机收益）
  - 即：中后期满分 ≈ 25 秒挂机收益；**早期保底 30**（新号一局 ≈ 一次首购）
- 0 分也消耗次数；**中途退出（Esc/关闭/点面板外）也消耗次数并结算**
  - 已玩 **<2 秒：退还次数**（不消耗、无奖励）——防手滑；免确认
  - 2–28 秒：弹**确认框**「结束会按已完成比例结算并消耗 1 次」
  - 时长系数保证**早退拿不到全额奖励**（<1/3 时长按比例缩水）
- 最高分记录在存档（**上限 8000**，与 save 净化一致）；**破纪录有「🎉 新纪录」提示 + 旧值对比**
- 🎮 按钮显示**剩余次数角标**；次数用尽显示「今天玩完了，明天再来」+ 按钮「明天再来」
- 结算页显示：分数 / **本局奖励 +N** / 新纪录或历史最高 / 分游戏明细（接住·漏接·最高连击 / 找对·找错 / perfect·漏拍）/ **再来一局**

| 游戏 | 玩法 | 计分 |
|---|---|---|
| **接咖啡** | 咖啡从上方掉落，点屏幕接住（时间窗 ±0.32s、横向 ±0.13） | 接住 +10，连击最高 ×2，漏接 -2（分数下限 0） |
| **找老板** | 3×3 脸里找出王总（红色「王」），**30 秒内无限轮**（原 5 轮改为限时） | 正确 +50、错误 -20（屏幕分/结算/早退 best 统一不含时间项） |
| **节奏点击** | 120 BPM 节拍，跟着点 | perfect(±80ms) +20、good(±160ms) +10；**乱点 -5、漏拍 -10**（防狂点）；晚按 240ms 内与漏拍合并，不双罚 |

## 存档净化
