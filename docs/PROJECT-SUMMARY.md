## 1. 这是什么

一款**手机竖屏优先**的「摸鱼」主题放置/点击游戏。纯前端（Vite + TypeScript + Canvas），零后端，存档在 localStorage，构建产物 52KB JS + 11KB CSS，可部署到任意静态托管。

## 2. 怎么玩

```bash
cd moyu
export PATH="$HOME/.nvm/versions/node/v22.23.2/bin:$PATH"   # 本机 PATH 默认 node16，需 ≥20
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # 产物在 dist/，丢到静态托管即可
npm test         # 159 例
```

**新手 30 秒**：打开页面 → 顶部是"摸鱼值"大数字 → 中间像素办公室 → 底部商店卡。按 HUD 下的绿色目标条「再戳 15 下 → 解锁咖啡续命」戳屏幕即可，卡片变亮后点一下买下。

**每天怎么玩（2-5 分钟）**：
1. 打开页面 → 自动结算离线收益（欢迎面板显示离开时长与规则）
2. 点几下 / 收同事丢来的梗 / 遇到老板巡逻时按横幅要求做（多数是"忍住别点"）
3. 在日报（右下 📔）领 3 个小目标的奖励
4. 花掉摸鱼值买升级（点击线提升每次点击，挂机线提升每秒自动收入）
5. 关页面（10 秒自动存档 + 关闭时存档）

**进阶**：攒钱等里程碑（每 20 级该档效果 ×2）→ 图鉴 55 收集 → 到达 1 亿解锁「离职再就业」（转生：重置余额与 20% 等级，换永久收益倍率）。

## 3. 玩法系统清单（v0.4.0 实际数值）

| 系统 | 当前实现 |
|---|---|
| 点击 | 基础点击力 1；连击间隔 <0.5s 累积、漏两拍（>1.0s）断、20 连封顶 ×1.24 |
| 挂机 | 底薪 0.2/秒；挂机线 6 档（手机/蹲坑/群聊/会议/深度摸鱼/退休式躺平） |
| 升级 | 9 档（3 点击线 + 6 挂机线），价格 ×1.15^等级，每 20 级该档效果 ×2（按表序错峰偏移 0/5/10/15） |
| 老板巡逻 | 每 90-150s（首次 20-35s）；3 变体：hold 忍住 / type 点 5 次 / blitz 点 16 次（奖 ×1.5）；前 3 次新手保护不罚 |
| 偷点 | 巡逻期点击照给收入，但每击罚 0.6×挂机秒收益（单次巡逻封顶 10×）；0.8s 反应宽限，宽限内无收入无罚款 |
| 安然连胜 | 连续安然 N 次奖励 ×(1+0.1N)，封顶 ×1.5；被抓清零；已入存档 |
| 同事丢梗 | 45-75s 一次（首次 12-25s），5 秒内戳中 +5×点击力 + 收集语录；文案归属「老周」 |
| 每日日报 | 每 6 小时一个窗口（4 段/天）；3 目标；固定含「上线看一眼」「挂机涨钱」两个自动目标，保证零操作可完成；奖励 max(500, 600×挂机秒收益) |
| 图鉴 | 55 格（10 语录 + 9×5 彩蛋）；挂机线按等级、点击线按累计点击 100/500/3000/8000/20000；每 5 格 +2% 永久挂机（55 格 +20%） |
| 段位 | 14 档（实习生 → 摸鱼宇宙尽头·终，最高 3.2e11），按生涯累计 |
| 转生 | 本局累计 ≥1e8×当前倍率解锁；点数 floor(3×(本局/1e8)^0.4) 单局封顶 20；每点永久 +75%（线性）；重置余额与 20% 等级，保留图鉴/日报/段位/历史累计 |
| 离线 | 日常 12h 封顶、≥7 天 24h、≥30 天 48h；首日全额、之后基础 70%，当日每次回访 +10%（最多 3 次 → 100%）；≥7 天回归统一走当前离线效率（95% 硬上限） |
| 剧情 | 6 章工位便签（随生涯进度换）+ 4 套职员配色随章节切换 + 角色：小余/王总/老周/小美 |
| 音效 | WebAudio 程序化点击音（音高随连击）、成功双音、静音开关 |
| 其他 | 本地生涯纪录、统计面板、存档码导出/导入、版本号+更新日志、PWA manifest + Service Worker（离线可用） |

## 4. 十轮试玩闭环与修掉的问题

共 **10 轮有效闭环**（R4 因模型 key 失效作废），**35 个 subagent 玩家实例**，画像不重复（数值党/休闲党/审计/养成/多玩法/挑战/新手/留存/UX/硬核/暴躁/付费/女性向/竞品/学生/数据/云存档/佛系/音游/中老年/平板/回归/极简/剧情/排行榜/运营/宠物/像素/色弱…）。

### 4.1 功能级（P0，会让玩家玩不下去）

| 问题 | 来源 | 修复 |
|---|---|---|
| 切后台后收益丢失约 99.7%（rAF 被暂停 + dt 钳制） | R1 休闲党探针 | `resume.ts` 按真实时钟差补结算，离场≥5s 即补算并弹面板 |
| `src/style.css` 从未被装配 → 整站无样式、面板无法关闭 | R1 审计探针 | `main.ts` 顶部 `import "./style.css"` |
| 精灵坐标双重缩放 → 手机上角色/电脑全在画布外 | R1 审计探针 | 统一虚拟坐标系，场景按虚拟单位布局 |
| 一张图 404 全游戏黑屏（输入绑定在 await 之后） | R1 审计探针 | 输入/循环先行、8s 加载超时、失败降级占位、启动失败横幅 |
| 可领奖励时 📔 按钮飞出屏幕（`position` 被覆盖，y=-141）→ 手机上无法领奖 | R11 无障碍探针 | 去掉 `.has-reward` 的 `position` 覆盖 |
| 职员精灵 404（改名后代码未同步）→ 画面只剩占位色块 | R11 宠物/像素探针 | 重新接线 `worker-0..3.png` 四套配色 |
| 日报「上线/挂机」目标无计数 hook → 约 80% 天数无法完成日报 | R10 回归党探针 | 补 visit/idle 计数；日报固定含两个自动目标 |
| 存档导入后被 `pagehide` 旧状态覆盖（导入静默失效） | R10 排行榜探针 | 导入后置 `suppressSave` 并停自动存档 |

### 4.2 平衡/经济（会让游戏"不好玩"或"没盼头"）

| 问题 | 来源 | 决策 |
|---|---|---|
| 纯挂机开局死局（点 10 下也永远 0 收入） | R1 数值党 | 新增底薪 0.2/秒；九档表重排 |
| ×1.15 曲线过快饱和、30 分钟后购买无感 | R1 数值党 | 效果里程碑 ×2/20 级 + 错峰偏移 |
| 事件经济占比 14.6-19.2% 超红线 | R5 验收 | 奖励 4×挂机秒、连胜封顶 ×1.5（实测 5.7-9.6%） |
| 偷点在 ≥3cps 变成无脑连点（100% 占优） | R5/R6 挑战党 | 每击 0.6×挂机秒、按实收累计封顶、与余额脱钩、宽限不给收入 |
| 转生 7 天内净亏 42 倍（越早转越亏） | R8 竞品党 | 线性 +75%/点、保留 80% 等级、门槛随倍率涨（7 天：不转 620e8 < 见转 1184e8 < 攒够 3383e8） |
| 1e8 刷转生 134 次成为最优 | R8 竞速党 | 点数按"本局/当前倍率"归一化 |
| 生产包暴露 `__MOYU__.rewindSave`（一键 8h 离线作弊） | R8 竞速党 | 仅 `import.meta.env.DEV` 暴露，生产包已剥离（dist 验证 0 命中） |

### 4.3 数据/信任

- 存档无备份 → **存档码导出/导入**（base64url + FNV 校验、导入前备份旧档、重置 savedAt 防重复刷离线）+ 版本迁移链（接受 v≤当前、更高版本先备份）
- 存档可注入非法值 → 跨字段钳制 `lifetime ≥ total ≥ moyu`、等级/图鉴/streak 净化
- 欢迎面板把"封顶后结算时长"当离开时长 → 改为显示真实离开时长并标注上限
- 段位双口径（HUD 用 lifetime、toast 用 total）→ 统一；罚款不再扣历史累计（段位不倒退）

### 4.4 留存/内容

- 段位 7 档 D3 打穿 → 扩到 14 档（至 3.2e11）
- 离线效率从固定 0.7 → 回访可挣回 100%
- 日报 1 次/天 → 6 小时窗口（4 段/天），跨窗口保留同目标进度
- 图鉴 43/55 死锁（点击线彩蛋需等级）→ 点击线改按累计点击解锁；加成改分段（每 5 格 +2%）
- 内容零叙事 → 6 章便签 + 4 套配色 + 角色台词归属（老周/王总/小美）
- 大屏横屏/桌面角色被裁 → scale 宽高双约束；宽屏限宽 900 居中；键盘空格/回车可摸鱼

### 4.5 体验/无障碍

- 新手无引导 → HUD 目标链（再戳 N 下 → 解锁 X）+ 卡片首次可买弹入动画
- 字号过小/对比度不足（中老年画像 3/10）→ 正文 14-15px、面板 13-14px、canvas 横幅 16px+、3 处对比度修复
- 手抖误买 → 大额购买二次确认；买不起点击给"还差 X"提示
- 读屏不可用 → aria-live 播报巡逻/丢梗/购买确认、模态 role+Esc+焦点、移除禁止缩放
- 无音效 → WebAudio 程序化点击音 + 连击 HUD + 静音开关
- 无"活着"信号 → 版本号 + updates.json + 📔「关于」+ 今日工位梗 + SW 更新提示
